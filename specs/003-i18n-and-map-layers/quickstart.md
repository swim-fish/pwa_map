## 3. Smoke-test walkthrough

After a clean `npm run dev`, visit `http://localhost:5173` and:

### US1 — Switch the map layer

1. The toolbar at the top right shows three buttons: `前往`,
   `格式`, plus the new `圖層` button.
2. Click `圖層`. The picker opens with a grouped list:
   - **Other**: `OpenStreetMap` (active by default).
   - **NLSC**: `NLSC 電子地圖（等高線+門牌）`.
   - **Google**: `Google 衛星混合`, `Google 純衛星`,
     `Google 地形`, `Google 路線圖`.
   - Below a separator: `Google 路網疊加層` (toggle).
3. Click `NLSC 電子地圖（等高線+門牌）`. The picker closes; the
   map repaints with NLSC tiles within ~1 s; the attribution bar
   now reads `© 內政部國土測繪中心 (NLSC)`.
4. Reopen `圖層`, click `Google 衛星混合`. The map shows the
   Google hybrid tiles with localised place names in Traditional
   Chinese.
5. Toggle `Google 路網疊加層`. The road network appears layered
   on top of the satellite tiles.
6. Reload the page. The same basemap + overlay state is restored.

### US2 — Switch the UI language

1. Click the new `語言` toolbar button. The picker lists `中文`,
   `English`, `日本語` with the active locale highlighted.
2. Click `English`. Every visible UI string switches to English
   immediately. The Google basemap labels remain in Traditional
   Chinese (the `hl=zh-TW` URL parameter is fixed).
3. Reload the page. The interface stays in English.
4. Switch to `日本語`. UI strings are now Japanese; Google labels
   still in Traditional Chinese.

### US3 — Tile cache offline parity

1. Pan the map at zoom 13 over the Greater Taipei area on
   `NLSC 電子地圖`. The tiles paint progressively.
2. Open DevTools → Network tab → set throttling to `Offline`.
3. Pan within the area you just covered. Cached NLSC tiles still
   render.
4. Switch the basemap to `Google 純衛星`. Already-cached satellite
   tiles render; uncached areas show the missing-tile placeholder.

### Edge case — tile-failure toast

1. Block `https://wmts.nlsc.gov.tw/*` in DevTools (Network →
   Block request URL). Switch the basemap to `NLSC 電子地圖`.
2. Within ~5 s a localised toast appears
   (`NLSC 圖磚載入失敗，已退回上一個圖層`) and the previous
   basemap (e.g., OSM) is restored. Map remains usable; canvas is
   never blank.

```bash

npm run test
npm run test:e2e -- --grep "story-3c"
```

`npm run build && npx vite-bundle-visualizer` and trim the largest
delta — the new code is mostly catalogue + two pickers, which should
each compile to < 1 KB gzipped.
